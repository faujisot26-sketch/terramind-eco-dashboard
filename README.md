# TerraMind Eco Dashboard

Source files for the TerraMind Eco Dashboard UI and supporting data/services.

## Files

- `terramind_eco_dashboard-2.tsx` — dashboard application component
- `src/components/` — header, sidebar, and methodology modal components
- `src/constants.ts` — baseline values and initial application data
- `src/services/geminiService.ts` — Gemini request helpers
- `src/types.ts` — shared TypeScript types

The component files were placed at the paths used by the dashboard imports. The provided files do not include package metadata or the remaining application setup, so this repository contains the source bundle rather than a fully configured runnable project.
